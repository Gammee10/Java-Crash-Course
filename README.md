# Java Crash Course

This repository contains coding exercises I completed while taking a Java crash course. It is a personal practice project for learning Java fundamentals.

## Topics

- **Java basics:** student grade average
- **Control flow:** multiplication tables, score checks, and summing numbers
- **Arrays and strings:** finding a maximum value and counting vowels
- **Classes and objects:** a simple student class
- **Methods and code organization:** finding the maximum of two numbers
